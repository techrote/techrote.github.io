ANSI TOOLING / 02

PNG2ANSI

An offline browser port of pyANSI. Load an image, fit it to CP437 cells and the classic Windows Terminal palette, then download ANSI, PNG preview or a reusable JSON profile.

OPENGITHUB

Output

The default canvas is 80×40 cells. Output uses CP437 cell bytes, 16 foreground colours and eight classic background colours; no SAUCE footer is added.

Fitting

Photographic and industrial fitting modes are available. Local ANSI references can replace the built-in glyph vocabulary with a frequency-ordered union.

Packaging

The release artifact is one HTML file and makes no network requests. Conversion runs in a worker and stale jobs are rejected when settings change.
