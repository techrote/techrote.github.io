UNICODE GLYPH EDITOR / 02

GlyphPoint

Draw and arrange Unicode character art on a colour-aware grid. GlyphPoint runs as a single self-contained HTML application, with a viewport-based Canvas 2D editor and no account or server requirement.

OPEN EDITORGITHUBMANUAL

Draw and compose

Use pencil, fill, text, shapes, selections and transforms. Each cell can hold a full Unicode grapheme, its own foreground and background colours, and supported text styling. Move, rotate, mirror, resize or skew regions, with explicit edge-handling choices.

Save and exchange

Browser-local recovery checkpoints help restore interrupted work. Save editable v3 JSON projects, export whole-field PNG, standalone HTML or plain text, and print your artwork. Native direct saving is available in supported browsers; others offer a download fallback.

Run offline

Open the hosted editor here, or download GlyphPoint-RC.html to run locally. The editor and default DejaVu Sans Mono font are bundled. Recovery stays within the current browser profile and site origin; keep a separate project file for portable backups.

2.0.0-rc.1 is a qualified development candidate, not a published release. Automated CI passed for the current source commit; physical-device and assistive-technology acceptance, and a project-license decision, remain outstanding.
