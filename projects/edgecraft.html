MESH FINISHING / 04

EdgeCraft

A triangle-mesh finishing kernel with a browser editor. It works on closed piecewise-planar meshes and returns replacement triangle meshes.

OPENGITHUB

Operations

Edge finishing supports chamfer, fillet and Chamfillet profiles. Vertex finishing includes chamfer, Flatillet, fillet and Chamfillet patches.

Architecture

STL I/O, mesh analysis and finishing are separated. The browser editor uses the same core API instead of keeping a second geometry implementation.

Limits

This is not a B-rep or NURBS kernel. Edge finishing is limited to closed, consistently wound, convex two-face manifold creases, with conservative local clamping.
