REFERENCE CONVERTER / 03

pyANSI

The Python reference implementation for converting raster images into 80-column-compatible CP437 ANSI art.

GITHUB

Output

PNG2ANSI.py writes a .ans file and a PNG preview from the same fitted cells. Defaults are 80×40, photographic fitting and the full printable CP437 vocabulary.

Control

Profiles can be stored as versioned JSON. Command-line options cover style, vocabulary, preprocessing and ANSI reference input.

Boundary

It intentionally excludes UTF-8 true colour, SAUCE metadata, playback helpers and image-specific drawing overlays.
