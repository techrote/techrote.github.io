Relay Moth Forest

A small atmospheric exploration game about restoring a strange mechanical forest, gathering relay moths and helping robots through increasingly elaborate night-time environments.

PLAYGITHUB

Current milestone

Pretty Graphics Edition 4.14 combines source-normal/specular sprite materials, dynamic shadows, SurfaceFX water and fine grass, rooted physical foliage, casual robot followers, wildlife and a full on-canvas WYSIWYG room editor.

Browser build

The hosted build mirrors the runtime HTML, JavaScript and JSON from the canonical repository. Large sprite/material atlases are loaded from the exact source commit using CORS-enabled GitHub raw assets, keeping the Pages repository small while preserving the canonical art.

Editor note

F2 opens the WYSIWYG editor. GitHub Pages cannot write back to the repository, so SAVE / DOWNLOAD MAP downloads the edited map JSON. Direct project saving with timestamped backups remains available through the source repository's local Python launcher.
