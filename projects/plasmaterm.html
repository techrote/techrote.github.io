PlasmaTerm

A lightweight real-time plasma visualizer built around direct keyboard control. The main project targets Windows Terminal; the site carries a Python/WASM web build.

OPENGITHUB

What it does

Spatial frequency, hue range, speed, hue shift, radius, palette size and frame rate are adjustable from the keyboard. Presets and LUTs can be loaded directly.

How it works

The patterns are deterministic combinations of simple mathematical waves rather than Perlin or Simplex noise. Configuration files can be edited while the program is running.

Web build

The browser version is a separate, less-performant portable build. The current hosted page identifies itself as PlasmaTerm web-v0.2b.
