CHARACTER PAINTING / 01

GlyphPaint

Paint-style drawing and image editing on a coloured character grid, in a standalone browser app.

GITHUB

Draw with glyphs

Use brushes, flood fill, text, shapes and selections. Each cell holds a glyph, foreground and background colours, a font and text attributes.

Import and export

Import images or coloured HTML, save editable JSON projects, and export selectable-text HTML, plain text or images.

Run locally

Download GlyphPaint.html from the repository and open it in a desktop browser. No server, installation or external assets are required.
