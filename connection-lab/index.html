What these numbers mean

This is an Internet workload, including your browser, Wi-Fi, router, ISP, and the remote host. It cannot identify packet loss or prove which part caused a pause. Parallel HTTP requests may share one HTTP/2 connection.

A pause means at least 2 seconds with no browser progress while a transfer is pending. Planned reading breaks do not count. Upload progress can run ahead of server receipt; the saved report separates browser-reported bytes from server-confirmed requests. Browser buffering and background-tab throttling can affect the graph.

Downloads use fresh URLs and already compressed images or incompressible binary data. Rates count application payload, excluding TCP, Wi-Fi, and TLS overhead. MB and Mbps use decimal units. Keep this tab in the foreground and the screen on. A hidden tab is marked in the report.

GitHub Pages is static hosting, so Upload and Both ways send random test data to Cloudflare’s public speed-test endpoint. No files, credentials, or ESP diagnostics are uploaded. If that endpoint is blocked or unavailable, those modes report the error; Browse and Download remain independent. Results stay in this browser unless you save or copy them.

The data budget limits requested payload; network overhead and the small upload availability check are additional. Stop and the time limit cancel outstanding requests. A test is not started again automatically.
